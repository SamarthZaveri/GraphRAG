    03 / EVALUATION

    Does routing pay off?

    Two benchmarks. FinQA: single report pages, with numeric answers scored by an exact scalar check. SEC EDGAR: real earnings releases, 3 companies × 2 quarters per sector, so questions span documents. Text answers are scored by a blinded LLM judge. The router is fit on train rewards and frozen; dev and test are held out, and test sectors never appear in training. Error bars are bootstrap 95% CIs.
